# PHP CRUD Application with Docker & MySQL

โปรเจกต์เว็บแอปพลิเคชันระบบจัดการข้อมูลสมาชิก (CRUD: Create, Read, Update, Delete) พัฒนาด้วย **PHP** และ **MySQL** รันระบบผ่าน **Docker** พร้อมตกแต่งหน้าตาด้วย **Bootstrap 5** และไอคอน **FontAwesome 6**

---

## 🚀 คุณสมบัติระบบ (Features)
- ➕ **Create:** เพิ่มข้อมูลสมาชิกใหม่ (ชื่อ, นามสกุล, อีเมล, เพศ)
- 📋 **Read:** แสดงรายการสมาชิกทั้งหมดพร้อมระบบแจ้งเตือน (Alert Messages)
- ✏️ **Update:** แก้ไขข้อมูลสมาชิก
- 🗑️ **Delete:** ลบข้อมูลสมาชิกออกจากระบบ
- 🗄️ **phpMyAdmin:** มีระบบจัดการฐานข้อมูลผ่านเว็บเบราว์เซอร์

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **Backend:** PHP 8.x
- **Database:** MySQL
- **Frontend:** HTML5, Bootstrap 5, FontAwesome 6
- **Containerization:** Docker & Docker Compose
